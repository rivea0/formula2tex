# Formula2TeX

A Vue application to copy TeX source of basic discrete math formulas to clipboard.


### Example Usage




https://github.com/user-attachments/assets/17874ab8-eed9-41b4-9b35-eaba9599306d





### To run locally:

Clone the repository:

```
git clone git@github.com:rivea0/formula2tex.git
```

`cd` into it:

```
cd formula2tex
```

Install dependencies:

```
npm install
```

Run the server:

```
npm run dev
```
