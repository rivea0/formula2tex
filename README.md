# Formula2TeX

A Vue application to copy TeX source of basic discrete math formulas to clipboard.


### Example Usage


https://github.com/rivea0/discrete-math-ref/assets/58330360/8977f6e2-c4b6-44eb-b1a5-97eb61c782bc


### To run locally:

Clone the repository:

```
git clone git@github.com:rivea0/formula2tex.git
```

`cd` into it:

```
cd formula2tex
```

Install dependencies:

```
npm install
```

Run the server:

```
npm run dev
```
